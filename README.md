# Атлас — дашборд погоды и курсов валют

Веб-приложение без сборки и зависимостей: погода по городу, прогноз, курсы валют, график динамики и компактный экран-виджет для телефона.

## Запуск

Нужны только Node.js 18+ и браузер. Ключи API не требуются.

```bash
npm start
```

Затем открыть http://localhost:3000

Иконки PWA уже сгенерированы. Если нужно пересоздать их:

```bash
npm run icons
```

## Возможности

- Поиск города с подсказками (Open-Meteo Geocoding) и определение местоположения через `navigator.geolocation`.
- Текущая погода: температура, ощущается, влажность, ветер, осадки, максимум/минимум дня.
- График температуры на 24 часа с вероятностью осадков.
- Прогноз на 7 дней с полосками диапазона температур.
- Курсы валют относительно выбранной базы, поиск по коду/названию.
- График динамики выбранной пары за 30 дней (Frankfurter / ЕЦБ).
- Переключатель °C / °F, кэш в `localStorage` (погода 10 мин, курсы 30 мин, тренд 6 ч), ручное обновление.
- В часах одновременно время выбранного города и местное время телефона; подпись города и дата без года.
- **Избранное**: несколько городов, быстрый переход по чипсам, сохранение между сеансами.
- **Погодные предупреждения**: мороз, жара, сильный ветер, грозы, ливни; опционально — уведомления браузера (не чаще раза в час).
- **Конвертер валют** с актуальным курсом и кнопкой «поменять местами».
- **График динамики за 7 / 30 / 90 дней** с процентом изменения.
- Дополнительные данные: видимость, давление, УФ-индекс, восход и закат.
- Кнопка «Поделиться» (Web Share API или копирование ссылки), индикатор офлайна, горячие клавиши `/` (поиск) и `r` (обновление).
- Обновлённые unit-тесты чистой логики: `npm test`.
- Адаптивная верстка для телефонов: одна колонка, компактные карточки и часы поверх контента.
- PWA: установка на главный экран Android, офлайн-оболочка через service worker.

## Мини-экран «Виджет»

Откройте `/?widget=1` — останется только компактная карточка:

- время выбранного города;
- дата без года и день недели;
- город;
- погода (иконка, температура, описание);
- местное время телефона.

В `manifest.webmanifest` есть ярлык **«Виджет»**: на Android долгое нажатие на иконку приложения → «Виджет» → «Добавить на главный экран».

Важно: это **ярлык/мини-приложение**, а не системный Android-виджет. Браузерная страница не может обновляться на рабочем столе при закрытом приложении.

Настоящий системный виджет лежит в папке **`android/`** — это отдельный нативный проект на Kotlin/Glance с обновлением через WorkManager. См. [android/README.md](android/README.md).

## Источники данных

- [Open-Meteo](https://open-meteo.com/) — погода и геокодинг, без ключа.
- [ExchangeRate-API (open access endpoint)](https://www.exchangerate-api.com/docs/free) — актуальные курсы, без ключа.
- [Frankfurter](https://frankfurter.dev/) — исторические курсы ЕЦБ для графика.

Динамика доступна только для валют, которые публикует ЕЦБ. Для RUB, KZT, UAH и некоторых других пар график скрывается с пояснением.

## Структура

```
index.html            — разметка
styles.css            — стили, адаптив и виджет-экран
core.js               — чистые функции (погода, единицы, предупреждения)
app.js                — логика, запросы, кэш и графики
tests/core.test.js    — unit-тесты (npm test)
server.js             — статический сервер и прокси /api/trend
sw.js                 — service worker (офлайн-оболочка)
manifest.webmanifest  — PWA-манифест и ярлык «Виджет»
icon.svg, icon-*.png  — иконки PWA
scripts/make-icons.js — генерация PNG-иконок
android/              — нативный Kotlin-проект с системным виджетом
```

Курсы носят информационный характер и не являются коммерческим предложением.
