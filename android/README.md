# Атлас — Android-приложение с настоящим виджетом

Нативный проект на Kotlin + Jetpack Compose. В отличие от веб-версии, это **реальный системный виджет Android**: он живёт на главном экране и обновляется сам, даже когда приложение закрыто.

## Что внутри

- **Glance-виджет** на главном экране: время города, дата без года, день недели, город, иконка и температура, **местное время телефона** и первое погодное предупреждение; нажатие открывает приложение.
- **WorkManager** обновляет виджет каждые 15 минут при наличии сети; кнопка ↻ в приложении запускает немедленное обновление.
- **Уведомления о непогоде**: мороз, жара, сильный ветер, грозы и ливни; не чаще одного уведомления в час. На Android 13+ запрашивается разрешение `POST_NOTIFICATIONS`.
- **DataStore** хранит город, единицы, базовую валюту, последний ответ погоды и время последнего уведомления — виджет показывает кэш сразу, без сети.
- **Retrofit + Gson** — Open-Meteo (погода/геокодинг), ExchangeRate-API (курсы), Frankfurter (динамика).
- **Compose UI**: поиск города, текущая погода (включая видимость, давление, УФ-индекс, восход/закат), 24 часа, 7 дней, курсы валют, переключатель °C/°F.
- Material 3, адаптив под телефон, minSdk 26 (Android 8.0).

## Готовый APK

Каждый коммит в `main` запускает GitHub Actions, который собирает APK и публикует его как артефакт **atlas-debug-apk** во вкладке репозитория **Actions**. Откройте последний зелёный запуск → **Artifacts** → `atlas-debug-apk` → скачать и установить на телефон (разрешите установку из неизвестных источников).

При публикации тега `v1.0` и выше тот же APK автоматически попадает в **Releases** — оттуда его тоже можно скачать без сборки.

## Сборка вручную

1. Установите **Android Studio** (Ladybug или новее) и Android SDK 34.
2. Откройте папку `android/` через **File → Open**.
3. Дождитесь синхронизации Gradle (wrapper уже лежит в репозитории).
4. Запустите на эмуляторе или телефоне: **Run → app**.
5. На главном экране: долгое нажатие на пустое место → **Widgets** → **Атлас — погода и время**.

Ключи API не нужны.

## Структура

```
app/src/main/java/ru/atlas/weather/
  AtlasApp.kt              — Application, контейнер зависимостей, планировщик
  MainActivity.kt          — Compose-экран
  data/Models.kt           — DTO и снимок погоды для виджета
  data/Api.kt              — Retrofit-клиенты
  data/Repository.kt       — загрузка, преобразование, кэш
  data/SettingsStore.kt    — DataStore настроек
  ui/Theme.kt, ui/WeatherScreen.kt
  util/WeatherCodes.kt     — коды погоды WMO
  util/WeatherAlerts.kt    — правила погодных предупреждений
  widget/AtlasWidget.kt    — UI виджета (Glance)
  widget/AtlasWidgetReceiver.kt
  widget/WidgetUpdater.kt  — WorkManager
```

## Известные ограничения

- Расписание обновления фиксировано (15 мин). Система Android может задерживать фоновые задачи в энергосберегающем режиме — это поведение ОС.
- Геолокация в нативную версию пока не добавлена: город выбирается поиском.
- Проект собран на версиях библиотек 2024 года; при открытии в свежей Android Studio Gradle предложит обновить версии — это нормально.
